# 發大財家庭基金

香港情侶與家庭共用的記帳網頁。介面為繁體中文書面語，金額以港幣計算。兩部手機可以登入同一個帳號，也可以各自註冊，再用 6 位邀請碼加入同一個家庭。離線時新的支出會先存在這部手機，連線後自動同步。

## 環境

- Node.js 22 或更新版本（使用內建的 `node:sqlite`）
- npm

## 安裝與啟動

```bash
npm install
cp .env.example .env.local
npm run dev
```

瀏覽器打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

正式環境：

```bash
npm run build
npm start
```

資料存在 `data/family-fund.db`。這個檔案不會進 git。若要回到乾淨的示範資料，先停掉伺服器，刪除該檔案，再重新啟動。

## 示範帳號

不用設定 OAuth。登入頁有「使用示範帳號登入」。

| 人物 | 電郵 | 密碼 | 角色 |
| --- | --- | --- | --- |
| Alex | `demo@9fmoney.hk` | `familyfund` | 男朋友 |
| May | `partner@9fmoney.hk` | `familyfund` | 女朋友 |

兩人已在同一個家庭。邀請碼是 `9FM88K`。想看「加入家庭」，可用無痕視窗註冊新帳號再輸入邀請碼。同一個瀏覽器只會保留一個登入狀態。

## 邀請碼怎麼運作

1. 第一位註冊後選擇「建立家庭基金」，並選擇自己是男朋友或女朋友。
2. 系統產生 6 位邀請碼（不含容易混淆的 0／O／1／I）。示範家庭固定為 `9FM88K`。
3. 伴侶另行註冊，在「加入伴侶的家庭」輸入邀請碼。一個家庭最多兩位成員，第二位會自動得到另一個角色。
4. 之後兩邊看到的支出、食譜、願望與設定都是同一份。
5. 若兩部手機只是登入同一個帳號，不需要邀請碼，帳目一樣會同步。每一筆支出仍可自選付款人。

邀請碼可在「設定」查看與複製。

## 離線暫存

記一筆、修改、刪除，以及「記今日煮過」，在沒有網絡時會寫進瀏覽器的本地佇列。頁首狀態：

- **已同步**：佇列是空的
- **同步中**：正在送出
- **離線暫存**：還有紀錄留在這部手機

恢復連線後會自動送出。伺服器以每筆動作的編號避免重複寫入。設定、新增食譜與 CSV 匯出需要連線。

## 匯出 CSV

設定頁的「匯出全部支出（CSV）」會下載 UTF-8 檔案，並在開頭加上 BOM，Excel 可直接顯示中文。金額欄是數字，沒有千分位。

## 環境變數

電郵登入不需要任何金鑰。OAuth 只有在填了對應變數後才會導向 Google 或 X；否則按鈕會回到登入頁並說明尚未設定。

在 Google Cloud 或 X 開發者後台登記的重新導向網址：

- Google：`{來源}/api/auth/oauth/google/callback`
- X：`{來源}/api/auth/oauth/x/callback`

本地來源預設是 `http://127.0.0.1:43123`。若對外網址不同，設定 `APP_URL`（不要結尾斜線）。

```bash
APP_URL=http://127.0.0.1:43123
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
X_CLIENT_ID=
X_CLIENT_SECRET=
```

X 需要 OAuth 2.0，並允許讀取帳號電郵（`users.email`）。沒有電郵的帳號會被拒絕，請改用電郵註冊。

## 畫面

| 路徑 | 內容 |
| --- | --- |
| `/login`、`/register` | 電郵登入／註冊，Google、X 按鈕，示範帳號 |
| `/setup` | 建立家庭或輸入邀請碼 |
| `/` | 本月總支出、共同目標、雙方對比、類別分佈 |
| `/entry` | 記一筆；`/entry/[id]` 為編輯支出 |
| `/ledger` | 月份、篩選、共同／個人、編輯與刪除 |
| `/report` | 男朋友或女朋友、本月／上月／自訂、個人與共同 |
| `/life` | 演唱會示範清單、家居食譜 |
| `/settings` | 邀請碼、稱呼、目標、類型、願望、CSV、登出 |

未登入會被帶到 `/login`。尚未加入家庭的帳號只會看到 `/setup`。

## 資料說明

消費類型預設：餐飲、交通、娛樂、購物、居家、旅行、醫療、其他。支付類型預設：現金、信用卡、八達通。示範家庭另外有 PayMe。已被支出使用的類型不能刪除。

演唱會清單是相對今天產生的示範資料，狀態包含售票中、已售罄、已完結、即將開售，並非即時票務。介面上已註明日後可接上自動更新。

共同目標為 0 時視為關閉，總覽只計算標記為「共同」的支出。
